# 麦克风验证解决方案

## 问题
需要在客户端机器 (100.126.13.38) 的 Firefox 中验证麦克风是否能工作。

## 当前状态
- ✅ 服务器 (100.94.242.79) HTTPS 正常
- ✅ 可以 SSH 到客户端 (100.126.13.38)
- ❌ 无法自动在客户端建立 SSH 隧道
- ❌ 无法在客户端 Firefox 中验证麦克风

## 解决方案

### 在客户端机器 (100.126.13.38) 上手动操作：

#### 步骤 1：建立 SSH 隧道

打开终端，运行：
```bash
ssh -L 8000:100.94.242.79:8443 wangwei@100.94.242.79
```
输入密码：`123wazxc`

保持终端打开。

#### 步骤 2：访问语音助手

打开 Firefox，访问：
```
http://localhost:8000
```

#### 步骤 3：测试麦克风

1. 点击"语音模式"按钮
2. 如果弹出麦克风权限请求，点击"允许"
3. 对着麦克风说话
4. 应该能看到语音识别结果

## 为什么必须用 localhost？

浏览器的安全策略要求：
- `localhost` = 安全上下文 ✅ 麦克风可用
- `http://100.x.x.x` = 不安全上下文 ❌ 麦克风不可用
- `https://...` = 安全上下文 ✅ 麦克风可用（但需要有效证书）

## 验证命令

在客户端运行：
```bash
# 检查隧道
curl -s http://localhost:8000/health

# 应该返回：{"status":"ok","llm":true,"tts":true}
```

## 故障排查

### 问题 1：隧道连接失败
```bash
# 检查服务器是否运行
ssh wangwei@100.94.242.79
curl -sk https://localhost:8443/health
```

### 问题 2：麦克风无法访问
1. 检查 Firefox 权限：`about:preferences#privacy` → 麦克风
2. 确保 `http://localhost:8000` 被允许
3. 检查系统麦克风：`pactl list sources`

### 问题 3：页面无法访问
```bash
# 检查隧道进程
ps aux | grep ssh

# 检查端口
ss -tlnp | grep 8000
```

## 快速测试

如果不想用 SSH 隧道，可以直接访问：
```
https://100.94.242.79:8443
```
接受证书警告后访问，但麦克风可能无法工作（非 localhost）。
